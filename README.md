# Retail Sales & Inventory Intelligence Platform

An end-to-end data portfolio project focused on turning retail sales and inventory data into useful business insights and predictions.

## Project Goal

The goal of this project is to build a complete retail analytics solution that can help a business:

- monitor sales, revenue and profit,
- understand product and branch performance,
- identify low-stock and reorder situations,
- analyze customer behaviour,
- forecast future product demand,
- support decisions through Power BI dashboards and machine learning.

## Planned Tech Stack

- Python
- Pandas
- SQL
- PostgreSQL
- Power BI
- Machine Learning
- Streamlit
- Docker
